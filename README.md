# STRATELLA – AI-Powered CRM for Medical SMEs

## Overview
STRATELLA is an intelligent CRM analytics platform that uses AI and Data Science to convert unstructured sales and medical data into clean, reliable, and actionable insights for improved commercial performance and strategic decision-making.

This project was developed as part of the PIDEV – 4th Year Engineering Program at **Esprit School of Engineering (Academic Year 2025–2026)**.

The platform is specifically designed for medical SMEs such as private clinics and healthcare centers, helping them improve patient relationship management, automate workflows, and enhance decision-making using advanced AI technologies.

---

## Features
- Patient and client relationship management  
- Appointment and follow-up automation  
- AI-powered report generation (LLM-based)  
- Predictive analytics (sales forecasting & segmentation)  
- Sentiment analysis on patient feedback  
- OCR + NLP for document processing  
- Business Intelligence dashboards (KPIs & insights)  
- Secure handling of sensitive healthcare data

## Architecture
STRATELLA follows a modular AI-driven architecture:

- **Frontend Layer:** Web CRM interface  
- **Backend Layer:** API & business logic (Spring Boot)  
- **Orchestration Layer:** Agent management and routing  

### AI Agents:
- **OCR + NLP Agent:** Extracts and processes documents  
- **Reporting Agent (LLM):** Generates structured reports  
- **Predictive ML Agent:** Forecasting and classification  
- **Sentiment Analysis Agent:** Analyzes patient feedback  

### Data Layer:
- CRM Database (clients, sales, orders)  
- Operational data & indexes  
- Knowledge Base (Vector DB for RAG)  

### Analytics Layer:
- Business Intelligence dashboards  
- KPI monitoring and predictive insights
